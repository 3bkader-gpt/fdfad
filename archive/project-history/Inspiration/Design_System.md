# Design System for "فضفاض"

## 1. Color Palette

- **Primary (Sophistication):** `#4A5D4E` (Muted Sage - suggests modesty and elegance).
- **Secondary (Warmth):** `#E5D3C5` (Sand/Beige - natural, neutral).
- **Accent (Call to Action):** `#B38E7E` (Warm Taupe - visible but not aggressive).
- **Background:** `#FAFAFA` (Soft White).
- **Text:** `#2D2D2D` (Charcoal - softer than black).

## 2. Typography

- **Headings:** "Playfair Display" (Serif) - Elegant, high-end feel.
- **Body:** "Inter" (Sans-serif) - Highly legible on mobile, clean.

## 3. Spacing & Layout

- **Grid:** 4-column mobile grid.
- **Spacing:** 8pt grid system.
- **Border Radius:** 8px for cards, 4px for buttons (balance between soft and structured).

## 4. Components

- **Product Card:** Large image, clean text (Name, Price), minimalist "Quick Add" button.
- **Buttons:** Full-width on mobile. Rounded corners. Secondary button has outline style, Primary has solid fill.
