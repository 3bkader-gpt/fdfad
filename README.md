# فضفاض (Fadfaad) - Modest Fashion Ecommerce

Fadfaad is a mobile-first modest fashion ecommerce platform specifically designed for the Egyptian market. It aims to solve the operational friction of manual WhatsApp-based ordering by providing a structured, high-trust digital boutique experience.

## Tech Stack
- **Frontend:** Next.js 14+ (App Router), Tailwind CSS, TypeScript.
- **Backend:** Supabase (PostgreSQL, Auth, Storage).
- **Deployment:** Vercel.

## Getting Started

### 1. Prerequisites
- `pnpm` installed.
- Supabase project created.

### 2. Environment Setup
Copy `.env.example` to `.env.local` and fill in your Supabase credentials:
```bash
cp .env.example .env.local
```

### 3. Installation
```bash
pnpm install
```

### 4. Development
```bash
pnpm dev
```
